# תגרשן לי

מלווה דיגיטלי לגירושין בישראל — ידע משפטי, צ'ק-ליסט ומחשבונים.

## התקנה

```bash
npm install
npm run dev
```

פתחו [http://localhost:3000](http://localhost:3000)

## פקודות

- `npm run dev` — שרת פיתוח
- `npm run build` — בנייה ל-production
- `npm run test` — בדיקות חישוב מזונות
- `npm run lint` — ESLint

### גרסה 3 (נוכחית)

- עוזר חכם (חיפוש במאגר ידע + FAQ)
- תמיכה ב-4 עדות (יהודים, מוסלמים, נוצרים, druze)
- מחשבון קצבת מזונות — ביטוח לאומי
- שיתוף חישוב בין הורים (קישור + QR)
- רשימת אנשי מקצוע (עו"ד, טוענים, מגשרים)

## הערה משפטית

האפליקציה מספקת מידע והערכות בלבד. היא **אינה** מהווה ייעוץ משפטי.

## תיעוד

ראו `PLAN.md` לתוכנית המלאה ומחקר משפטי.
